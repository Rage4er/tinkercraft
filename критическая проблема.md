### 🔴 КРИТИЧЕСКАЯ ПРОБЛЕМА: Фигуры отображаются плоскими (2D), а не 3D

**Описание:**
При создании примитивов (куб, сфера, цилиндр, конус) через manifold-3d, фигуры визуализируются как плоские (2D) объекты вместо полноценных 3D-тел. Это делает невозможным использование всех 3D-инструментов.

**Вероятные причины:**

1. **Неправильный порядок осей в `Manifold.cube()`**
   ```typescript
   // ❌ НЕПРАВИЛЬНО (возможно, передаётся только 2 параметра)
   const cube = wasm.cube([width, height]); // только 2D!
   
   // ✅ ПРАВИЛЬНО (должно быть 3 параметра)
   const cube = wasm.cube([width, height, depth]);
   ```

2. **Ошибка в передаче параметров из UI в CSG Worker**
   ```typescript
   // Проверить, что параметры фигуры содержат все три измерения
   interface ShapeParams {
     width: number;   // X
     height: number;  // Y
     depth: number;   // Z — ВАЖНО: не пропустить!
   }
   ```

3. **Неправильная конвертация manifold → Three.js Mesh**
   ```typescript
   // Проверить, что геометрия содержит Z-координаты
   const positions = mesh.vertProperties; // должны быть [x,y,z, x,y,z, ...]
   // Если Z всегда 0 → фигура плоская
   ```

**Диагностика:**

```typescript
// Добавить в код отладки:
console.log('Manifold mesh vertices:', mesh.vertProperties);
// Проверить, что Z-координаты не равны 0
const hasZ = mesh.vertProperties.some((v, i) => i % 3 === 2 && v !== 0);
console.log('Has Z-coordinates:', hasZ);
```

**План исправления:**

1. **Проверить `worker.ts`** — убедиться, что все примитивы создаются с 3 параметрами
2. **Проверить `shapes/`** — генераторы примитивов должны возвращать полноценные 3D-тела
3. **Добавить unit-тесты** — проверять, что у созданной фигуры есть объём (bounding box не плоский)
4. **Визуальная проверка** — добавить отображение bounding box для отладки

**Пример правильного создания примитивов:**

```typescript
// ✅ ПРАВИЛЬНО: куб 20×10×30 мм
const cube = wasm.cube([20, 10, 30]);

// ✅ ПРАВИЛЬНО: сфера радиусом 15 мм (3D)
const sphere = wasm.sphere(15, 32);

// ✅ ПРАВИЛЬНО: цилиндр радиусом 10 мм, высотой 25 мм
const cylinder = wasm.cylinder(10, 25, 32);

// ✅ ПРАВИЛЬНО: конус радиусом 12 мм, высотой 20 мм
const cone = wasm.cone(12, 20, 32);
```

**Временное решение (если проблема в UI):**
Добавить принудительную проверку в `addShape`:
```typescript
// В document-store.ts
const addShape = (shapeType: string, params: Record<string, number>) => {
  // Убедиться, что для куба переданы все 3 измерения
  if (shapeType === 'cube' && !params.depth) {
    params.depth = params.width || params.height || 10; // fallback
  }
  // Аналогично для других фигур
};
```
