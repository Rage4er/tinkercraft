## 🛠️ Инструменты (TinkerCAD-совместимость)

| Инструмент | Функция | Статус в TinkerCraft | Горячая клавиша |
| :--- | :--- | :--- | :--- |
| **Копировать** | Копирует выбранный объект в буфер | ✅ Есть | Ctrl+C |
| **Вставить** | Вставляет скопированный объект | ✅ Есть | Ctrl+V |
| **Дублировать (Ctrl+D)** | Создаёт копию объекта в том же месте | ❌ Отсутствует | Ctrl+D |

| **Отменить** | Отменяет последнее действие | ✅ Есть | Ctrl+Z |
| **Вернуть** | Возвращает отменённое действие | ✅ Есть | Ctrl+Y |
| **Группировать** | Объединяет несколько объектов в один (CSG union) | ✅ Есть | — |
| **Разгруппировать** | Разделяет сгруппированный объект на отдельные части | ❌ Отсутствует | — |
| **Выровнять** | Выравнивает объекты по оси X/Y/Z | ✅ Есть | L |

| **Показать все** | Отображает все скрытые объекты | ❌ Отсутствует | — |
| **Рабочая плоскость** | Разместить новую рабочую плоскость на грани объекта | ❌ Отсутствует | W |
| **Линейка** | Измерить расстояние между двумя точками | ✅ Есть | — |

## 🎯 Приоритетные задачи (рекомендованный порядок)

### 🟡 Высокий приоритет (MVP+)

1. **Дублировать (Ctrl+D)** — базовая операция, очень часто используется — 🔲 **Фаза 8+**
2. **Умное дублирование** — TinkerCAD-совместимость: повтор последней трансформации для каждой новой копии — 🔲 **Фаза 8+**
3. **Блокировка объектов** — предотвращение случайного перемещения/редактирования (поле `locked` уже есть в SceneObject, но UI не реализован) — 🔲 **Фаза 8+**
4. **Рабочая плоскость (W)** — размещение новой рабочей плоскости на грани для построения в произвольной ориентации — 🔲 **Фаза 8+**
5. **Изометрическая резьба** — востребованный генератор для 3D-печати — 🔲 **Будущее**

### 🟢 Низкий приоритет (позже)

6. **Разгруппировать** — требует хранения истории CSG-операций с возможностью отмены — 🔲 **Будущее**
7. **Сплошное/Отверстие** — требует ролей объектов (только для дочерних объектов в группе) — 🔲 **Будущее**
8. **2D Эскиз** — большая задача, требует отдельной подсистемы (2D canvas, констрейнты, проекция на плоскость) — 🔲 **Будущее**
9. **Генератор изображений** — конвертация изображения в height map, построение меша — 🔲 **Будущее**
10. **Каракули (Scribble)** — рисование 2D-контура, триангуляция, экструзия — 🔲 **Будущее**
11. **Шестерня** — параметрическая генерация зубчатого колеса через manifold — 🔲 **Будущее**
12. **Ячейки Вороного** — генерация структуры Вороного внутри bounding box — 🔲 **Будущее**

## 📝 Технические заметки

### Дублирование (Ctrl+D)
- В store уже есть clipboard (`itemIds`), но дублирование — это не то же самое что Copy+Paste
- Дублирование: копирование + вставка одним действием с offset'ом (без использования буфера)
- Умное дублирование: повтор последней `move`-операции с той же delta

### Блокировка
- `SceneObject.locked` уже определён в типах (`types.ts`)
- Нужен UI: кнопка «Замок» в панели свойств или тулбаре
- Гизмо должно игнорировать заблокированные объекты в raycaster

### Рабочая плоскость (Workplane)
- Требует: выделение грани → ориентация плоскости → трансформация gizmo в эту систему координат
- Сложность: изменение системы координат для всех последующих операций добавления фигур

### 2D Эскиз
- Самая крупная задача: 2D canvas поверх WebGL, constraint solver, триангуляция
- Аналог в TinkerCAD: "Scribble" → "Extrusion" pipeline
- Возможный подход: SVG-путь → `THREE.Shape` → `ExtrudeGeometry` → manifold

### Генератор резьбы
- Формула: спираль → `Manifold.revolve()` или построение через `Manifold.warp()`
- Параметры: диаметр, шаг резьбы, количество витков, сегменты на оборот
