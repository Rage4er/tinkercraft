# Идеи развития TinkerCraft Web

Здесь собираются идеи и направления развития проекта на перспективу.
Отбор и реализация лучших идей происходит по мере готовности проекта.

## 📋 Список идей

### 1. 🎮 Публикация на Яндекс Игры

**Статус:** Идея
**Сложность:** Средняя
**Приоритет:** Высокий

**Суть:** Выложить проект на платформу Яндекс Игры с бесплатным доступом.

**Что потребуется:**
- Адаптация UI под мобильные устройства (тач-управление)
- Интеграция SDK Яндекс Игр (реклама, лидерборды, достижения)
- Добавление игровых механик (уровни, достижения, челленджи)
- Оптимизация производительности для мобильных браузеров
- Подготовка скриншотов и описания для каталога

**Механики для встраивания:**
- Уровни с заранее заданными задачами (собери конструкцию по образцу)
- Система достижений (первая модель, 10 операций CSG, сложная геометрия и т.д.)
- Челленджи и таймер (собери объект за ограниченное время)
- Галерея работ пользователей

**Монетизация:**
- Баннерная реклама (AdSense / Яндекс РСЯ)
- Межстраничная реклама между уровнями
- Премиум-функции (экспорт в STL/PNG высокого разрешения, шаблоны)

### 2. 🎮 Игровые механики + Рекламная интеграция

**Статус:** Идея
**Сложность:** Высокая
**Приоритет:** Высокий

**Суть:** Единая система игрового процесса и монетизации через токены и рекламу. Разделено на игровые механики (геймплей) и рекламную интеграцию (монетизация без вреда для опыта).

---

#### 🎮 ИГРОВЫЕ МЕХАНИКИ (ГЕЙМПЛЕЙ)

##### 1. Режим "Свободное творчество" (Sandbox)
- **Что это:** Базовый режим — игрок строит всё, что хочет, без ограничений.
- **Игровая ценность:** Экспорт STL, сохранение в облако, участие в рейтингах.
- **Монетизация:** Токены за экспорт, покупка новых фигур.

##### 2. Режим "Ежедневный вызов" (Daily Challenge)
- **Что это:** Каждый день новое задание с четкими условиями.
- **Примеры заданий:**
  - "Создай модель объемом ровно 5000 куб. единиц"
  - "Используй минимум 3 разных фигуры"
  - "Сделай модель с симметрией > 80%"
  - "Собери домик из 10 деталей за 2 минуты"
- **Награда:** Токены (10-20 шт), уникальные фигуры, место в отдельном лидерборде.
- **Почему работает:** Ежедневный контент — причина возвращаться каждый день.

##### 3. Режим "Гонка на время" (Speed Build)
- **Что это:** Игроку показывают модель (или дают текстовое описание), нужно повторить её за минимальное время.
- **Сложность:** Легкая (5 деталей), средняя (10 деталей), сложная (15+ деталей).
- **Награда:** Бонусные токены в зависимости от времени, место в таблице рекордов.
- **Почему работает:** Азарт + соревнование, идеально для коротких сессий.

##### 4. Режим "Турнир недели" (Weekly Tournament)
- **Что это:** Тематический конкурс (например, "Космический корабль", "Средневековый замок").
- **Механика:** Игроки создают модели по теме, они оцениваются автоматически (балл за сложность) или голосованием (если будет сервер).
- **Награда:** Эксклюзивные фигуры, тонны токенов, звание "Мастер недели".
- **Почему работает:** Долгосрочная мотивация, комьюнити.

##### 5. Режим "Квесты и достижения" (Achievements)
- **Что это:** Система долгосрочных целей.
- **Примеры:**
  - "Создай 100 моделей" → 50 токенов
  - "Используй каждую фигуру хотя бы раз" → новая фигура "Тор"
  - "Экспортируй 50 STL" → премиум-цвет
  - "Набери 1000 баллов оценки" → статус "Мастер"
- **Почему работает:** Дает чувство прогресса, удерживает на месяцы.

##### 6. Социальная механика (с вашим сервером)
- **Что это:** Галерея работ, лайки, комментарии.
- **Как работает:** Игроки выкладывают скриншоты моделей, другие оценивают.
- **Награда:** Токены за популярность, место в топе.
- **Почему работает:** Признание сообщества — сильнейший мотиватор.
- ⚠️ **Заметка:** Это требует вашего сервера (Firebase/Supabase), поэтому на старте необязательно.

#### 🎯 РЕКЛАМНАЯ ИНТЕГРАЦИЯ (6 способов)

| Механика | Где в игре | Как работает | Ценность для игрока | Доходность |
| :--- | :--- | :--- | :--- | :--- |
| **1. Отключение баннера** | Верхний правый угол UI | Показ видеорекламы → баннер исчезает на сессию | Чистый интерфейс, нет отвлекающих элементов | ⭐⭐⭐⭐⭐ (высокая) |
| **2. Бонусные токены** | В магазине или после оценки | За просмотр видео игрок получает токены | Пополнение баланса для экспорта | ⭐⭐⭐⭐⭐ |
| **3. Ускорение экспорта** | Кнопка "Экспорт STL" | Реклама вместо платы токенами (или сокращает время ожидания) | Экономия токенов | ⭐⭐⭐⭐ |
| **4. Разблокировка фигур** | Раздел "Новые фигуры" | Посмотри рекламу → получи новую фигуру (тор, винт) | Прогресс, новые возможности | ⭐⭐⭐⭐ |
| **5. Дополнительная попытка** | Режим "Гонка на время" | Проиграл → посмотри рекламу → попробуй еще раз | Не терять прогресс | ⭐⭐⭐ |
| **6. Ежедневный супер-бонус** | Главный экран, 1 раз в день | Просмотр рекламы → 20 токенов (вместо обычных 5) | Большая награда за небольшие усилия | ⭐⭐⭐⭐ |

#### 🧩 СХЕМА ВЗАИМОДЕЙСТВИЯ

```
ИГРОК
↓
Выбирает режим:
- Свободное творчество (экспорт STL)
- Ежедневный вызов (задание + награда)
- Гонка на время (соревнование)
- Турнир недели (тематический конкурс)
↓
Для каждого действия нужны ТОКЕНЫ
↓
ТОКЕНЫ можно:
- Заработать (ежедневный бонус, оценки, достижения, просмотр рекламы)
- Купить (Яндекс.Покупки)
↓
РЕКЛАМА помогает:
- Убрать баннер (на сессию)
- Получить больше токенов (видео)
- Разблокировать фигуры (видео)
- Ускорить экспорт (видео)
↓
ИТОГ: игрок доволен (выбирает), вы получаете доход (монетизация)
```
