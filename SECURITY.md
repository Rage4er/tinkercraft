# Политика безопасности

## Сообщить об уязвимости

Если вы обнаружили уязвимость в безопасности, **не создавайте публичный Issue**.

Свяжитесь с нами через приватные каналы:

1. **GitHub Security Advisories** — [github.com/Rage4er/tinkercraft/security/advisories/new](https://github.com/Rage4er/tinkercraft/security/advisories/new)
2. **Telegram** — укажите в Issue с меткой `security` (создаст приватный канал)

Пожалуйста, включите в отчёт:
- Описание уязвимости
- Шаги для воспроизведения
- Влияние (что может сделать злоумышленник)
- Возможное решение (если есть)

## Время отклика

| Этап | Срок |
|---|---|
| Подтверждение получения | 48 часов |
| Первичная оценка | 5 дней |
| Исправление или mitigation | 30 дней (для критических — быстрее) |

## Scope

**В scope:**
- XSS через импорт файлов (STL, .doodle)
- Инъекции в IndexedDB
- Уязвимости зависимостей (manifold-3d, three.js, jszip)

**Не в scope:**
- Self-XSS (выполнение кода в собственной консоли)
- DoS через создание огромного количества объектов
- Проблемы браузеров (не нашего кода)

## Безопасные практики в коде

- Валидация пользовательского ввода: `sanitizeParams()`, `clamp()` в `worker.ts`
- Нет `eval()`, `Function()`, `innerHTML` с пользовательскими данными
- WASM-модуль инициализируется через `as unknown as ManifoldAPI` (единственное `any`)
- COOP/COEP заголовки для изоляции SharedArrayBuffer
