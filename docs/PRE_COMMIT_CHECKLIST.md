# 🛡 КОМПЛЕКСНЫЙ ЧЕК-ЛИСТ ПОСТ-РЕФАКТОРИНГА v1.0

**Когда применять:** после любой правки, затрагивающей экономику, сохранения, i18n, platform-слой, действия игрока (export/import/CSG/зеркало/цвет).
**Время полной проверки:** ~15 минут.

## 📋 СЕКЦИЯ A. SDK Яндекс.Игр — соответствие платформе

### A.1 Критичные (без них модерация отклонит)

- [ ] **`LoadingAPI.ready()`** вызван после полной инициализации (`initPlatform()` + загрузка данных). Индикатор 🟢 в debug-панели должен загореться **до** отображения игрового UI.
- [ ] **`GameplayAPI.start/stop`** вызываются корректно:
  - `stopGameplay()` при открытии модалки (экспорт, импорт, подписка, настройки, менеджер проектов)
  - `startGameplay()` при закрытии модалки
  - **НЕТ** рекламы во время `startGameplay()` (в момент редактирования модели)
- [ ] **SDK-скрипт инжектится только в yandex-сборке** (проверить исходник `dist-yandex/index.html` — есть `<script src="https://yandex.ru/games/sdk/v2">`; в `dist/index.html` — отсутствует).
- [ ] **COEP-заголовки правильные:**
  - `pnpm dev` (clean) — заголовки есть (нужны для WASM)
  - `pnpm dev:yandex` — заголовков нет (SDK должен грузиться)

### A.2 Рекомендуемые

- [ ] **Вся экономика обёрнута в `isYandex`:** в clean-сборке нет ни одной кнопки с бейджами, ни одного упоминания токенов в UI. Проверить: `pnpm build` → открыть → PropertiesPanel пуст (или показывает только менеджер проектов).
- [ ] **`VITE_PLATFORM` корректно работает:** `__PLATFORM__ === 'yandex'` в Яндекс-сборке, `'clean'` в CAD-сборке. Проверить через `console.log` при инициализации.

## 💾 СЕКЦИЯ B. Сохранения — syncToCloud() и данные

### B.1 Действия, которые ДОЛЖНЫ вызывать syncToCloud()

Проверять вручную после каждой правки этих функций:

- [ ] `watchAdForTokens()` — просмотр рекламы за токены
- [ ] `purchaseSubscription()` — покупка Pro на 7/30 дней
- [ ] `purchaseDayPass()` — покупка 24ч-пасса (текст/палитра/баннер)
- [ ] `claimDailyBonus()` — ежедневный бонус
- [ ] `exportStl()` — экспорт (кэшбэк начисляется → нужна синхронизация)
- [ ] `importStl()` — импорт (обновляются лимиты)
- [ ] `rewardForUse()` — бонус +1 за использование фигуры/инструмента
- [ ] `completeQuest()` — завершение квеста (награда)
- [ ] `resetDailyCounters()` — сброс лимитов в полночь
- [ ] **Обновление онбординг-флага** (если реализован)

### B.2 Разделение хранилищ

Проверить соответствие:

| Данные | Где хранится | Метод |
|--------|--------------|-------|
| Токены | **Облако** | `setStats({ tokens })` |
| Подписка (expiry timestamp) | **Облако** | `setData()` |
| 24ч-пассы (expiry) | **Облако** | `setData()` |
| Счётчики дня, квесты, streak | **Облако** | `setData()` |
| Онбординг-флаг | **Облако** | `setData()` |
| Проекты (.doodle) | **Локально** | IndexedDB |
| Экспортированные STL | **Локально** | download API |
| UI-настройки, тема | **Локально** | localStorage |

### B.3 Тест-сценарий "перезагрузка страницы"

Запустить в `pnpm dev:yandex` (с SDK-dev-proxy):

1. Получить ежедневный бонус
2. Посмотреть 1 рекламу
3. Выполнить 1 квест
4. **Обновить страницу (F5)**
5. Проверить:
   - [ ] Баланс токенов восстановился
   - [ ] Ежедневный бонус показывает «до 00:00» (а не снова доступен)
   - [ ] Счётчик рекламы `1/3` сохранился
   - [ ] Квест отмечен как выполненный ✅

### B.4 Миграция данных

- [ ] Если изменилась структура `player.setData` — добавить миграцию по полю `version` в `yandex-sync.ts`
- [ ] Если добавлены новые поля — есть дефолтные значения в `game-store` (иначе `undefined` при загрузке старых сохранений)

## 🌐 СЕКЦИЯ C. Локализация (i18n)

### C.1 Автоопределение языка (критично для модерации)

- [ ] Язык определяется **при старте**, а не в процессе игры (через `ysdk.environment.i18n.lang`)
- [ ] Индикатор 文 в debug-панели становится 🟢 **до** появления игрового UI (допустима краткая загрузка на правильном языке)
- [ ] При отсутствии SDK (clean-сборка) — fallback на `navigator.language`

### C.2 Проверка всех заявленных языков (RU + EN)

Открыть debug-панель → SDK mocks → переключить язык. Для **каждого** языка проверить:

- [ ] **Все UI-тексты** переведены (кнопки, лейблы, тултипы, модалки)
- [ ] **Нет хардкода** русских/английских строк в JSX (`t('game.dailyBonus')`, а не `"Ежедневный бонус"`)
- [ ] **Экономические термины** переведены: токены, подписка, кэшбэк, реклама, ежедневный бонус
- [ ] **Названия квестов** переведены (15 квестов × 2 языка = 30 строк в i18n)
- [ ] **Категории и сложность** квестов переведены
- [ ] **Уведомления** (toast-сообщения) переведены
- [ ] **Числа и даты** форматируются по локали (для дат — ISO формат безопасен)

### C.3 Проверка i18n-файлов

- [ ] В `locales/ru.json` и `locales/en.json` **одинаковое множество ключей** (нет пропущенных)
- [ ] В JSX **нет прямых строк** — всё через `t('key')`
- [ ] Переменные в переводах: `t('unlock.forTokens', { n: 100 })` — работают для обоих языков

## ⚠️ СЕКЦИЯ E. Частые ловушки (что ломается при рефакторинге)

| Ловушка | Как проверить | Защита |
|---------|---------------|--------|
| Забыли `syncToCloud()` в новом действии | Тест «перезагрузка страницы» (B.3) | Code review |
| Забыли обернуть текст в `t()` | Поиск по JSX: `grep -r "русское слово" src/` | i18n-lint в CI |
| Локальное время вместо серверного | Поиск: `grep -r "new Date()" src/store/` → должно быть `platform.serverTime()` | Code review |
| Хардкод эмодзи в UI | Поиск: `grep -r "💎🎁📺" src/components/` → должны быть SVG | Code review |
| Бейджи появились в clean-сборке | `pnpm build` → открыть → проверить PropertiesPanel | Автотест |
| Реклама показалаcь во время геймплея | Открыть модалку → проверить консоль (`stopGameplay`) | Code review |
| Структура данных изменилась без миграции | Зайти с «старым» сохранением | Миграция по `version` |
| Пропущен перевод для нового языка | `pnpm dev:yandex` → SDK mocks → другой язык | Чек C.2 |

## 🚦 СЕКЦИЯ F. Быстрая проверка (3 минуты)

После каждой правки — **минимум:**

1. `pnpm typecheck && pnpm test` — должны пройти ✅
2. Открыть игру в `pnpm dev:yandex`, перезагрузить страницу — токен-баланс и бонус-статус должны восстановиться ✅
3. Переключить язык в SDK mocks — весь UI должен сменить язык ✅

Если эти три пункта зелёные — правка безопасна. Если хотя бы один красный — стоп, чиним.
