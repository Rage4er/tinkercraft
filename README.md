# TinkerCraft Web

TinkerCraft — браузерный 3D CAD-редактор. Параметрический 3D-редактор для образования и хобби, работающий прямо в браузере.

> Вдохновлён [CaDoodle](https://cadoodlecad.com) — оригинальное Java-приложение использовано как референс архитектуры и UX.
> Стек: **React + TypeScript + Three.js + manifold-3d (WASM)**.

---

## Возможности

- **7 примитивов** — куб, сфера, цилиндр, конус, тор, призма, пирамида
- **Размещение с привязкой (Plug & Play)** — клик по фигуре палитры → полупрозрачное превью на курсоре встаёт на грань объекта, сетку или плоскость оси (X / Y / Z) → клик — фигура стоит на плоскости; Enter — в превью (без него — рядом с прошлыми), Esc / правый клик — отмена
- **Размерные линии** — кнопка «Размер» (D): клик по точке объекта, клик по второй — размер привязан к объектам (сдвиг, поворот, масштаб, смена размеров пересчитывают число); Стандарт / С отступом / Проекция на XY, цвет, шрифт, высота текста; слой «Показать / скрыть», Delete; сохраняются в `.3dtc` (не в истории)
- **3D-текст** — генерация через TextGeometry с настройкой размера и глубины, латиница и кириллица; замкнутый меш — участвует в CSG (гравировка: куб − текст)
- **Булевы операции CSG** — Union, Subtract, Intersect (manifold-3d в Web Worker); N-арные: объединение N объектов — один CSG с N детьми, вычитание / пересечение — группа A против группы B: выделить A → «Вычитание» → выделить B → Enter (Esc — отмена)
- **Инструменты** — перемещение, вращение, масштаб (гизмо), зеркало, выравнивание по реальной геометрии (с учётом поворота)
- **Параметрическая история (v1.3.0)** — дерево CSG с правкой параметров детей, правка прошлых шагов move / mirror / extrude с каскадным пересчётом CSG, независимые копии CSG (зеркало, вставка), CSG для замкнутых STL
- **История операций** — полный undo/redo с таймлайном и фильтрацией; «Очистить сцену» — с подтверждением и отменой (Ctrl+Z)
- **Импорт/экспорт** — STL (бинарный), `.3dtc` (ZIP + JSON)
- **Автосохранение** — IndexedDB, восстановление сессии при перезагрузке (с уведомлением)
- **Горячие клавиши** — Ctrl+Z/Y/C/V/S/O/A, Del, F, H, G/R/S (гизмо), Tab (камера), L (линейка), M/N/B (зеркала), U/X/I (CSG), D (размер) — как в подсказках
- **Языки** — русский и английский интерфейс
- **Менеджер проектов** — несколько проектов в IndexedDB
- **Линейка** — измерение расстояний в 3D
- **ViewCube** — навигационный куб с drag-вращением
- **Темы** — тёмная/светлая
- **PWA** — манифест, COOP/COEP для SharedArrayBuffer

## Технологии

| Уровень | Технология |
|---|---|
| UI / Состояние | React 18 + Zustand 5 |
| 3D Рендеринг | Three.js r170 |
| CSG | manifold-3d (WASM, выделенный Web Worker) |
| Персистентность | IndexedDB + JSZip (.3dtc) |
| Сборка | Vite 6 + pnpm |
| Тестирование | Vitest 4 (932 теста, 75 файлов) + Playwright e2e (24, в CI) |
| Язык | TypeScript 5.7 (strict) |

## Быстрый старт

```bash
git clone https://github.com/Rage4er/tinkercraft.git
cd tinkercraft/web-app

pnpm install
pnpm dev          # dev-сервер на http://localhost:5000
```

```bash
pnpm build        # production-сборка в dist/
pnpm test         # запуск тестов (932 теста, 75 файлов)
pnpm typecheck    # проверка типов TypeScript
```
