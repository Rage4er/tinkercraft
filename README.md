## Что такое CaDoodle

**CaDoodle** — десктопное приложение для параметрического 3D-моделирования (Java/JavaFX). Упрощённый аналог Tinkercad для образования и хобби.

### Основные функции

- 🧊 Создание и редактирование 3D-объектов (примитивы + булевы операции)
- ✏️ Инструменты: перемещение, масштаб, вращение, зеркало, выравнивание, скругление, экструзия
- 📜 История операций с undo/redo (таймлайн)
- 💾 Нативный формат `.doodle` (ZIP-архив с JSON историей операций)
- 📤 Экспорт: STL, Blender, FreeCAD
- 📥 Импорт: STL, SVG, 3MF, OpenSCAD
- 🤖 Конструктор роботов (Robot Lab)

### Формат `.doodle`

ZIP-архив, содержащий:
- `model.json` — история всех операций (AddShape, Move, Resize, Fillet, Mirror и т.д.)
- `thumbnail.png` — превью проекта

Совместимость формата между веб-версией и оригинальным Java-приложением — **обязательное требование**.

## Целевой стек веб-версии

| Компонент | Технология |
|---|---|
| 3D рендеринг | Three.js |
| CSG операции | manifold-3d (WASM) в Web Worker |
| UI фреймворк | React + TypeScript |
| Стейт-менеджмент | Zustand |
| Работа с файлами | File System Access API + JSZip |
| Сборка | Vite + pnpm monorepo |
